# docu

개인 금융 실무 판단 훈련용 정적 사이트.

## 구성
- `index.html`: 화면
- `style.css`: 모바일 우선 스타일
- `app.js`: 문제 풀이, localStorage 기록, 백업/복원
- `questions.json`: 매일 추가되는 문제 데이터
- `robots.txt`: 검색엔진 크롤링 차단

## GitHub Pages
Repository Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` 선택 후 저장.

배포 후 기본 주소는 보통 `https://suhny08.github.io/docu/` 입니다.

> 주의: 저장소와 Pages가 public이면 URL과 소스는 완전한 비공개가 아닙니다. 현재는 로그인 없이 개인 사용한다는 전제입니다.
